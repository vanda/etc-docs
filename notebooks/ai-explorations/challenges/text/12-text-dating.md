# 12. Text Dating

## Problem

Also known as: Date detection, stylochronometry, historical manuscript dating (HMD)

**Problem Statement**

Date the creation of some textual content from the text.

**Related Problems**

  * Museum - Object Dating
  * Conservation - Object Dating

# 5. Object Image Description

## Problem 

**Problem Statement**

Generate a description of a cultural heritage object from a digital image varying the length from a paragraph summary of the object upto an essay length description.

**Related Problems**

For much research on this problem the following:

  * 7 Object image classification
  * 8 Object image labelling
  * 9 Object image caption

are all considered the same issue, namely the generation of a certain length of text based on an image, and they vary only in the length of text generated.

Some researchers do explictily focus on one area though, for example generating a full multi paragraph description as opposed to a single sentence caption or generating a grammatically correct sentence (aka a caption) instead of a sentence formed of a series of classes (labelling) i.e. "An etching depicting Hercules fighting centaurs" rather than "etching, centaurs, Hercules". It is not always clear in research though if the same meaning always applies - for some "etching, centaurs, hercules" is considered a caption. For the 4 problems here they are treated differently, like so:

  * Image keywords - etching, centaurs, Hercules
  * Image labels - 
  * Image caption - An etching depicting Hercules fighting centaurs
  * Image description - This etching depicts the Ancient Greek demi-god Hercules fighting against

## Variations

### Major Variations

  * 2/A - Describe the cultural heritage object rather than the image - (e.g. a photo of a watercolour is described as a watercolour instead of just the contents)
  * 2/B - Restrict keywords to those within a particular context (materials, techniques, place, etc)
  * 2/C - Restrict keywords known to those within a particular vocabulary (AAT, TGN, Iconclass)
  * 2/D - Combine 2M2 and 2M3

### Minor Variations

  * 2/1 - Output the keywords in multiple languages
  * 2/2 - if the image contains people, give names to them

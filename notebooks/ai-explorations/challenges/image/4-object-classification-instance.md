# 4. Object Classification (object class)

## Problem

**Problem Statement**

Identify those parts of an image that contains depictions of "objects" (likely cultural heritage) and return bounding boxes for them, with a classification of the particular instance of the object class.

**Problem Backgroud**

A common problem of finding and identifying objects in an images. In addition to the challenge of just detecting a class of object in the image of the cultural heritage object, in this case we also want to know the exact object. So if the class detected is a person, which person is depicted ? If a painting, which painting (within a painting).
